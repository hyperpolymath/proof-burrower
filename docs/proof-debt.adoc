Required by the estate Trusted-Base Reduction Policy: "Every proof-bearing
repo MUST maintain a `docs/proof-debt.md` (or `.adoc`)". This is that file.
Every soundness-relevant escape hatch in this repository is listed here
under exactly one of the three dispositions, or as debt.

The `unsafe` blocks in `crates/burrower-wasm/src/lib.rs` are the C-ABI
boundary of the WASM shim. They are Rust `unsafe`, not proof escape
hatches, and the policy's escape-hatch table scopes Rust/Haskell entries to
`unsafePerformIO` and `unsafeCoerce` "where used in soundness-relevant
positions". They are recorded in §4 anyway, because the ABI proofs that
would make them safe (ABI-1..5) do not exist yet, and that is the honest
reading of the situation.

  semantics (DOM-1). Grade 3: type-checks under
  `agda --safe --without-K --cubical-compatible`, 0 warnings, also clean
  under full `--cubical`. Agda 2.7.0.1, agda-stdlib 2.4, 2026-11-01.
- `verification/proofs/agda/Burrow/Ledger.agda` — the ledger read path and
  `no-launder` (DOM-2). Same toolchain, same flags, same date.

Entries are removed from this section once a translation leg or an
engineering proof supersedes them.

- (none)

There is no property-based or fuzz harness in this repository
(`tests/fuzz/` holds a README stating that no harness exists), so nothing
can honestly be claimed as budgeted. Recording a budget without a test
would be exactly the unfalsifiable "covered by tests" the policy rejects.

== (c) Necessary axiom

== 2. Corrected marker count

`docs/tech-debt-2026-05-26.adoc` §1 reports `Idr-blv = 6` for this
repository. That count is a **false positive**. All six hits are comments
that *prohibit* the marker, not uses of it:

* `verification/proofs/idris2/ABI/{Compliance,Foreign,Layout,Platform,Pointers}.idr:6`
  — "All proofs MUST be constructive (no believe_me, no assert_total)."
* `verification/proofs/idris2/ABI/Compliance.idr` plus
  `verification/proofs/README.adoc:45` — the banned-pattern list itself.

The repository contains **zero** real escape hatches: no `believe_me`, no
`assert_total`, no `postulate`, no `sorry`, no `Admitted`, no `Axiom`, no
`unsafeCoerce`. The cause is the one the Trusted-Base Reduction Policy
already retired for `TODO` markers — "grepping prose … measures the prose,
not the proofs" — and it should be reported upstream rather than triaged
here.

The absence of markers is not a clean bill of health. It reflects an empty
proof set: there is nothing to have escaped from.

== 3. What a Grade 3 result would look like here

Mathesis §5: "A proof is Grade 3 if it type-checks locally in Agda but has
not been translated to an independent foundational system." For this
repository the shortest honest path is one theorem about Burrower's own
contract handling, checked with:

[source,shell]
----
agda --safe --without-K --cubical-compatible verification/proofs/agda/<Module>.agda
----

with the Agda version and standard-library version recorded beside the
commit, per `PROOF-POLICY.adoc` §2.1. Anything less — a template file that
compiles, or a proof about `Data.List` — is not a receipt for this project
and must not be reported as one.
