= Proof Burrower Roadmap

== Current status (2026-10-05)

Pre-alpha, v0.0.1. Implemented and tested: goal parsing, corpus index and
Jaccard ranking, the three-specialist swarm, Isabelle attempt playbooks via
ECHIDNA, the `echidna.prove.result/1` consumer with legacy fallback, the
JSONL ledger, `burrower serve` (Unix socket), the tropical-types oracle
bridge, and the WASM shim. CI: `rust-ci` (fmt, clippy, test, audit,
llvm-cov 95% floor) and `Burrower proof safety` (live Isabelle e2e).

Not done: Lean/Coq dispatch, ledger locking, ISO timestamps (record ids
*are* UUIDv7 and goal ids UUIDv8, both minted only in `ids.rs`), any proof
about Burrower itself (see `PROOF-STATUS.adoc`), and any non-local ledger
backend — the workspace has no network or storage client and no async
runtime.

== Milestones

* [x] `index` / `find` / `swarm` / `attempt` / `ledger` / `serve`
* [x] Contract-based result parsing (`echidna.prove.result/1`)
* [x] UUIDv7 ledger record ids and UUIDv8 goal content ids (`ledger::new_id` is the single site)
* [ ] Bump the proof-safety ECHIDNA pin to a contract-speaking echidna

=== Grade 3 (estate graded-proof ladder)

Per `hyperpolymath/mathesis` §5 a result is Grade 3 when it is prototyped
and iteratively constructed in Agda and type-checks locally, before any
translation to an independent system.

* [x] Two first-party Agda theorems, type-checked with
      `agda --safe --without-K --cubical-compatible` and clean under full
      `--cubical`: `Burrow/Trust.agda` (receipt vs warrant) and
      `Burrow/Ledger.agda` (no-launder on the read path). Agda 2.7.0.1,
      agda-stdlib 2.4, 2026-11-01.
* [ ] Replace the `Properties.agda` template body with real theorems
      (DOM-3..6) or delete it
* [ ] Fix or delete `src/interface/ffi/src/main.zig` — 17 unexpanded
      `{{project}}` placeholders, does not compile
* [ ] Creusot contracts on `echidna_contract::parse_prove_result` and
      `serve::SocketGuard` (PROOF-POLICY §1: first-party Rust → Creusot)
* [ ] Idris2 ABI proofs ABI-1..5 connected to the crates they describe
* [ ] Dedukti recheck legs into Rocq and Lean for anything that reaches
      Grade 2i/2ii, recording `transported` or `re-proved` per leg. Both
      new modules are written to survive this: neither uses K, and both
      are warning-free under `--cubical`.

== Blockers

* echidna `prove --output json` must land upstream before the live e2e can exercise the contract path.
* The only VCL Rust client (`verisimdb-client`) is async (tokio + reqwest) against a crate with no async runtime that also targets wasm32, and whether it can be depended on from this public repo is unresolved. Both must be settled before any non-local ledger backend.
