== Gaps

* The live e2e runs against an echidna that predates `--output json`, so
  the contract path is covered only by fake binaries until the pin moves.
* No fuzzing of `extract_statement` or the socket protocol.
* `burrower-wasm` is tested natively; the `.wasm` artefact itself is not
  exercised in CI.
* The template shell scripts under `tests/` (`aspect_tests.sh`,
  `tests/e2e/template_instantiation_test.sh`,
  `tests/workflows/validate_workflows_test.sh`) test the RSR template, not
  Burrower.
